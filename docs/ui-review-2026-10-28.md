# Pemeriksaan frontend Flavory

Permintaan: tombol GitHub bulat hitam, tema maroon/putih/gelap, teks singkat tanpa memotong judul, dan koleksi Mustika Rasa tanpa database.

Cakupan: template aktif `product.blade.php`, stylesheet bersama dan home, navigasi/pencarian, katalog, detail, penulis resep, koleksi pribadi, menu, belanja, pengaturan, privasi, dan pembaca Mustika Rasa. View lama yang tidak memiliki rute aktif tidak dipakai sebagai acuan tampilan.

Temuan yang diperbaiki:

- Aksen amber/merah dan warna pencarian yang tetap terang di dark mode diganti token maroon sesuai tema.
- Eyebrow dan paragraf promosi berulang di home serta deskripsi kartu dipangkas. Judul dipertahankan.
- Tombol GitHub diberi nama aksesibel, target 56 px, fokus, safe area, serta jarak dari toast/footer.
- Judul halaman arsip diperkecil menjadi 24–34 px agar daftar dan kontrol cepat terlihat.
- Format wiki pada judul, tabel, dan daftar resep diubah menjadi teks aman. Sambungan resep antarhalaman tetap digabungkan.
- Navigasi menandai Mustika Rasa aktif pada detail resep.
- Batas delapan bahan sebelumnya dapat dilewati lewat pilihan cepat setelah menambah bahan kustom. Tes mereproduksi kegagalan tersebut, lalu penjagaan ditambahkan pada pilihan cepat.

Validasi:

- Build Vite berhasil.
- Tes Node: lima lulus, termasuk urutan 1.215 halaman, ID resep unik, dan kelanjutan Gulai Bagar pada halaman 230–231.
- Tes PHP: lima lulus, 49 assertions. Semua rute produk, termasuk arsip, berjalan dengan koneksi database yang sengaja tidak tersedia.
- Pemeriksaan browser mencakup pencarian, favorit, porsi, bahan, mode masak, timer, cetak, berbagi, draft, impor/ekspor, menu, belanja, dan ketahanan localStorage.
- Axe WCAG A/AA dan pengujian overflow pada tema terang/gelap, lebar 360/768/1440 px.
- Inspector desain halaman arsip: tidak ada temuan, overflow, gambar rusak, atau console error pada ketiga lebar tersebut. Hasil lokal: `/tmp/flavory-ui-inspect-final/report.json`.
- Screenshot home dan arsip pada kedua tema/ukuran diperiksa. Hasil lokal: `/tmp/flavory-home-light-1440.png` dan `/tmp/flavory-book-dark-360.png`.

Batas pemeriksaan: transkripsi historis belum diperiksa manual terhadap seluruh pindai. Segmentasi otomatis menghasilkan 1.642 entri, bukan jaminan seluruh resep telah terpisah sempurna. Semua halaman transkripsi tetap tersedia. Takaran/porsi/durasi historis tidak direka atau dikonversi ke fitur perencana. Uji browser memakai Chromium; tidak menguji Safari, Firefox, atau pembaca layar fisik.
